I realize there are at least three types of covariates.

  • Collected directly on the ship. Each cruise’s webpage shows a list of these. One probably needs to go over these manually, and selectively download them.
    • Also, there are measurements that are taken sparsely along a cruise track, sometimes at depth. These are only useful if they can be reasonably interpolated from the original resolution to the hourly level.
  • In situ drifter/float
    • Global Drifter Program: (1979-02-15 – 2019-08-07): tblGlobalDrifterProgram
    • Argo Float Core Profiles (1997-07-28 – 2024-06-09): tblArgoCore_REP_Jun2024
      • I’m guessing this is the latest updated version. Others include: tblArgoCore_REP_Feb2024, tblArgoCore_REP_Nov2023, tblArgoCore_REP
    • Argo Float Biogeochemical Profiles (2002-09-08 – 2024-06-08) tblArgoBGC_REP_Jun2024
      • I’m guessing this is the latest updated version. Others include: tblArgoBGC_REP, tblArgoBGC_REP_Feb2024, tblArgoBGC_REP_Nov2023, tblArgoBGC_REP_Jun2023
    • GEOTRACES Intermediate Data Product 2021 v2 - Seawater (2006-07-13 – 2018-11-22): tblGeotraces_Seawater_IDP2021v2
    • UCSD Argo Mixed Layer Depth Climatology Model 2022: tblArgo_MLD_2022_Climatology
      • Seems super relevant
      • Also similar to tblArgo_MLD_Climatology
  • Models (climatology)
    • Mercator-Pisces Biogeochemistry and Weekly Forecast (2011-12-31 to 2019-04-27): tblPisces_NRT
    • GOBAI-O2 Climatology v2.2 (Gridded Ocean Biogeochemistry from Artificial Intelligence - Oxygen)
    • Mercator-Pisces Biogeochemistry Daily Forecast Nutrients (2022-01-01 to 2025-07-18): tblPisces_Forecast_Nutrients
    • Darwin Biogeochemistry 3 Day Averaged Model (1994-01-03 to 2015-12-30): tblDarwin_Nutrient
    • World Ocean Atlas 2013 v2 Climatology: tblWOA_Climatology
    • MODIS Chlorophyll Concentration (2002-07-04 to 2022-06-10): tblModis_CHL
    • MODIS Photosynthetically Available Radiation Daily 9km (2010-01-01 to 2022-03-07): tblModis_PAR
  • Other less promising models
    • Mercator-Pisces Biogeochemistry Daily Forecast Car: (2022-01-01 – 2025-07-18): tblPisces_Forecast_Car
    • Mercator-Pisces Biogeochemistry Daily Forecast Pft: (2022-01-01 – 2025-07-18): tblPisces_Forecast_Pft
    • GOBAI-O2 Climatology v2.2 Gridded Ocean Biogeochemistry from Artificial Intelligence - Oxygen (UNknown time range): tblGOBAI_O2_v2_2_Climatology
    • Mercator-Pisces Biogeochemistry Daily Forecast Co2 (2022-01-01 to 2025-07-18): tblPisces_Forecast_Co2

So, a strategy is to go through these steps: - Manually co-localize the above tables and all sensible variables therein. - Examine the on-cruise measurements (from, e.g., https://simonscmap.com/catalog/cruises/MGL1704 for Gradients 2), by 1. Excluding any gated products (which will have lots of observations, thousands or tens of thousands), 2. Exclude any things that are related to other non-Seaflow cytometers (IFCB, or imaging flow cytobot, which measures large particles above 3microns, which is larger than the small picophytoplankton we want to study), 3. Exclude any datasets that have too few surface observations (fewer than 30 rows altogether, or in the “DEPTH” visualization tab, fewer than 30-ish observations on the surface.) 4. Exclude GRUMP altogether.

Next, for every model/climatology or drift/floater dataset, we need to use a for-loop that goes over a time radius of {1 hr, 1 day, 3.5 days, 14 days}, and a latitude+longitude box of side lengths {0.1 degrees, 1 degrees, 2 degrees, 5 degrees}.

datlist = mclapply(ids_final, function(id){

  ## Safely restarting cruises that don't exist
  if(file.exists(file = file.path(outputdir, "cmap-data", paste0(id, "-adaptive.RDS")))) return(NULL)

  ## Colocalize all variables
  reslist = lapply(1:nvar, function(ivar){
    tryCatch({

      varname = vars %>% pull(Variable) %>% .[ivar]
      tabname = vars %>% pull(Table_Name) %>% .[ivar]

      if(tabname %in% c("tblWOA_Climatology", "tblPisces_NRT", "tblCHL_REP", "tblModis_PAR")){
        param = list_of_params[[tabname]]
      } else {
        param = list_of_params[["other"]]
      }
      for(isize in 1:5){

        ## Increase the radius
        if(isize > 1) param$latTolerance = param$latTolerance + 0.1 * 4
        if(isize > 1) param$lonTolerance = param$lonTolerance + 0.1 * 4

        ## Perform the colocalization
        dt = along_track(id,
                         targetTables = tabname,
                         targetVars = varname,
                         temporalTolerance = param$temporalTolerance,
                         latTolerance = param$latTolerance,
                         lonTolerance = param$lonTolerance,
                         depthTolerance = param$depthTolerance,
                         depth1 = param$depth1,
                         depth2 = param$depth2) %>% as_tibble() 
        dt = dt %>% dplyr::select(!contains("_std"))

        ## Check the missing proportion
        dt_missing_prop = dt %>% summarize(naprop = mean(is.na(!!sym(varname)))) %>% unlist()
        ## print(dt_missing_prop)
        if(dt_missing_prop == 0) break
      }
      return(dt)
    }, error = function(e){
      return(NULL)
    })
  })
  lens = reslist %>% purrr::map(. %>% length()) %>% unlist()
  if(any(lens == 0)){ reslist = reslist[-which(lens == 0)] }
  if(length(reslist) > 0){
    fullres = reslist %>% purrr::reduce(full_join, by = c("time", "lon", "lat"))
    fullres = fullres %>% dplyr::select(!contains("_std"))
    saveRDS(fullres, file = file.path(outputdir, "cmap-data", paste0(id, "-adaptive.RDS")))
    ## saveRDS(fullres, file = file.path(outputdir, "cmap-data", paste0(id, "-adaptive.RDS")))
    return(NULL)
  }
  return(NULL)
}, mc.cores = length(ids_final), mc.preschedule = FALSE)
