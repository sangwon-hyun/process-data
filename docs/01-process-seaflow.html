3.1 Processing Seaflow data (only Gradients 1 through 5)

In this document, we will clean and bin the particle-level seaflow datasets (only Gradients 1 through 5).

This is the overall setup for binning/gridding.

3.2 Binning five Gradients cruises

First, we will carry out the actual binning.

Code 
## Focus on the Gradients cruises
cruises = c("SCOPE_16", ## G1
            "MGL1704", ## G2
            "KM1906", ## G3
            "TN397_740", ## G4
            "TN412_130") ## G5

for(cruisename in cruises){

  ## Read particle-level data.
  vct_dir <- str_glue("{raw_data_dir}/{cruisename}/{cruisename}_vct_slim")
  vct_files <- list.files(vct_dir, "\\.parquet$", full.names = TRUE)
  list_of_df = lapply(1:length(vct_files), function(ifile){ read_parquet(vct_files[ifile]) })
  vct <- bind_rows(list_of_df)
  invisible(gc())
  
  ## Do the actual gridding now
  vct["fsc_small_coord"] <- as.integer(cut(vct[["fsc_small"]],
                                           grid_bins[["fsc_small"]],
                                           labels = FALSE,
                                           right = FALSE))
  vct["pe_coord"] <- as.integer(cut(vct[["pe"]],
                                    grid_bins[["pe"]],
                                    labels = FALSE,
                                    right = FALSE))
  vct["chl_small_coord"] <- as.integer(cut(vct[["chl_small"]],
                                           grid_bins[["chl_small"]],
                                           labels = FALSE,
                                           right = FALSE))

  ## Remove beads
  vct = vct %>% filter(pop != "beads")
  
  ## Gridding the data and summing the Qcs in each 3d grid bin.
  gridded <- vct %>%
    group_by(date, across(ends_with("_coord")), pop) %>%
    summarise(Qc = sum(Qc), .groups="drop") %>%
    select(date, fsc_small_coord, chl_small_coord, pe_coord,  Qc) %>%
    arrange(date, fsc_small_coord, chl_small_coord, pe_coord)

  ## Aggregate to hourly level
  hourly_gridded <- gridded %>%
    group_by(date=floor_date(date, "1 hours"), across(ends_with("_coord"))) %>%
    summarise(Qc=sum(Qc), .groups="drop") %>%
    arrange(date, fsc_small_coord, chl_small_coord, pe_coord)
  invisible(gc())
  
  ## Each cruise's binned data is now saved to a file
  filename = paste0(cruisename, "-gridded-before-cleaning.csv")
  outfile = file.path(outputdir, filename)
  write.csv(hourly_gridded, file = outfile, row.names = FALSE) ## TODO: write into a folder named after the cruise..
  cat("wrote to", outfile, fill=TRUE)
}

3.3 Data cleaning notes

Next, we will clean/process the binned data.

Here are some points that came up while cleaning data.

  1. All binning was done using 80 bins in each direction (dimension). FSC in a given cruise usually occupies only 40-ish bins. So later, prior to fitting flowmix/flowtrend models, we should multiply the FSC bin number by 2.
  2. Most cruises have upper CHL censoring.
  3. G5 (TN412_130) PE values all fall in the bottom bin. Although at first glance these may look like censored points, they aren’t! We don’t and shouldn’t remove these! (They are more like truncated points.)
  4. I’ve found that G1 has a level jump in Prochlorococcus levels in the middle of the cruise. This is apparent from 1d plots and the series of 3d bin plots.
